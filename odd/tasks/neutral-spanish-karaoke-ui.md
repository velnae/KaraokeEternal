## Scope and language contract

- Directly replace owned text in the existing UI and its user-facing server responses. Do not add i18n, a selector, translation dictionary/abstraction, or dependency. Preserve behavior, payload shape, URLs, field names, permission rules, and queue/player authority.
- Include first run; sign-in, room joining and guest creation; account/users/rooms/preferences; library/local and YouTube search; queue/approval/house/operator/participant states; player, controls, overlays; header/progress; page title and document `lang`; dialogs, alerts, empty/loading/error/validation states; tooltips, placeholders, alt text and accessibility labels. Audit desktop and mobile/gesture paths, singular/plural, counts and time/date units.
- Do not translate code identifiers, action values, status/origin/source/role enums, field keys, technical logs (particularly canonical failure-log messages), comments, unrelated docs/tests, existing stored user content, room/song/channel names, paths, or third-party YouTube iframe UI. Preserve proper names and acronyms such as Karaoke Eternal, YouTube, WebGL, QR, CDG, ReplayGain, and GitHub. Imported CHANGELOG content is documentation rather than an owned UI string; translate the About modal's UI chrome only.
- UI-visible labels derived from enums/roles still need Spanish: map display text at the rendering point without changing persisted or transmitted values. Distinguish the application-authored server messages actually propagated to users from diagnostic-only exceptions/logs. Retain numeric error codes and constants; do not translate arbitrary third-party/API error bodies or user data.
- UI Spanish is neutral/professional (no regional slang). This task document, technical comments and test identifiers remain English; tests that assert actual UI text use Spanish. New default room/user-visible names, if any are discovered, may be translated only for future creation; never migrate saved names.

## Terminology and visible-text decisions

| Context | Spanish UI text / guidance |
| --- | --- |
| song; song request | canción; solicitud de canción |
| queue; queue a song | cola de reproducción; agregar a la cola |
| room; join room | sala; entrar a la sala |
| guest; participant; operator | invitado; participante; operador |
| house track / house pool | canción de la casa / canciones de la casa (operator-inserted tracks, not a participant request) |
| Play Next; up next | Reproducir siguiente; siguiente canción (short labels may use Siguiente) |
| FAIR rotation; FIFO | Turnos equitativos; orden de llegada; preserve `FAIR`/`FIFO` option values and explain behavior in help copy |
| pending approval / approved / rejected | Pendiente de aprobación / aprobada / rechazada (agree with solicitud or canción in context) |
| open/closed room; account roles | Abierta/Cerrada; invitado/usuario/administrador as display only; keep `open`/`closed` and `guest`/`standard`/`admin` values |
| library; media folder; player | biblioteca; carpeta de archivos multimedia; reproductor |

Prefer short action verbs and explicit karaoke meanings; retain dynamic names/titles verbatim inside translated surrounding sentences. Keep the existing brand title unchanged, but use `lang="es"` and translate the Player page-title suffix.
