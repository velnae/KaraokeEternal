## Terminology and visible-text decisions

| Context | Spanish UI text / guidance |
| --- | --- |
| song; song request | canción; solicitud de canción |
| queue; queue a song | cola de reproducción; agregar a la cola |
| room; join room | sala; entrar a la sala |
| guest; participant; operator | invitado; participante; operador |
| house track / house pool | canción de la casa / canciones de la casa (operator-inserted tracks, not a participant request) |
| Play Next; up next | Reproducir siguiente; siguiente canción (short labels may use Siguiente) |
| FAIR rotation; FIFO | Turnos equitativos; orden de llegada; preserve `FAIR`/`FIFO` option values and explain behavior in help copy |
| pending approval / approved / rejected | Pendiente de aprobación / aprobada / rechazada (agree with solicitud or canción in context) |
| open/closed room; account roles | Abierta/Cerrada; invitado/usuario/administrador as display only; keep `open`/`closed` and `guest`/`standard`/`admin` values |
| library; media folder; player | biblioteca; carpeta de archivos multimedia; reproductor |

Prefer short action verbs and explicit karaoke meanings; retain dynamic names/titles verbatim inside translated surrounding sentences. Keep the existing brand title unchanged, but use `lang="es"` and translate the Player page-title suffix.
